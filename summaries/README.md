# AG Academic Lecture Summaries

This directory contains the concise, print-ready summaries for the bilingual AI and electrical power systems courses.

## Publishing model

- The website remains the complete interactive academic reference.
- Each PDF is a concise review document, not a copy of the webpage.
- Every summary is fully bilingual: English and Arabic appear together throughout the document, including headings, explanations, equations, examples, figure captions, takeaways, and review questions.
- The Arabic content is not an abbreviated translation; it must preserve the same scientific meaning and coverage as the English content.
- Lecture summaries use the file pattern `lectureNN-summary.html` and later `lectureNN-summary.pdf`.
- Laboratory summaries use the file pattern `labNN-summary.html` and later `labNN-summary.pdf`.

## Standard summary sections

1. Cover and course identity | الغلاف وهوية المقرر
2. Learning Outcomes | مخرجات التعلم
3. Prerequisites | المتطلبات السابقة
4. Key Concepts | المفاهيم الأساسية
5. Core Equations or Algorithm | المعادلات أو الخوارزمية الأساسية
6. One concise worked example | مثال محلول مختصر
7. Key Takeaways | أهم النقاط
8. Review Questions | أسئلة المراجعة
9. References | المراجع
10. Continue Learning Online | تابع التعلم عبر الموقع

## References policy

- Preserve the scientific references already used in the corresponding lecture or laboratory page.
- Do not replace the established references with unrelated sources.
- Include the references at the end of every summary under `References | المراجع`.
- Keep the original bibliographic information whenever available: authors, title, publisher or journal, edition, year, volume, issue, pages, DOI, and stable link.
- Use numbered citations such as `[1]`, `[2]`, and `[3]` inside the summary when a scientific claim, equation, method, or figure is based on a source.
- References may remain in their original publication language, while the section heading and any explanatory notes remain bilingual.
- Before publishing each summary, compare its reference list with the corresponding full webpage to ensure that no previously used academic source is lost.

## Design requirements

- A4 portrait layout
- White print background
- Dark navy headings
- Blue accents for Course 1
- Gold accents for Course 2
- Readable Arabic and English typography
- Correct right-to-left Arabic flow
- No dark webpage backgrounds, transparency effects, or interactive-only elements
- Target length: 6–12 pages, excluding additional reference pages when needed

The shared source template is `summary-template.html` and the print stylesheet is `summary-print.css`.
