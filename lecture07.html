1. What is Deep Learning?

Deep Learning is a branch of Machine Learning based mainly on neural networks containing multiple hidden layers.

Deep networks learn increasingly abstract representations as information moves through successive layers.

1. ما هو التعلم العميق؟

التعلم العميق هو فرع من التعلم الآلي يعتمد بصورة أساسية على الشبكات العصبية متعددة الطبقات المخفية.

تتعلم الشبكات العميقة تمثيلات أكثر تعقيدًا وتجريدًا كلما انتقلت المعلومات بين الطبقات.

2. Shallow vs Deep Networks

Shallow Network

Usually one hidden layer or only a few layers.

Deep Network

Multiple hidden layers arranged hierarchically.

2. الشبكات الضحلة والعميقة

الشبكة الضحلة

تحتوي عادةً على طبقة مخفية واحدة أو عدد قليل من الطبقات.

الشبكة العميقة

تحتوي على عدة طبقات مخفية مرتبة بصورة هرمية.

3. Hierarchical Feature Learning

Each layer transforms the representation produced by the previous layer.

Raw Input
→
Simple Features
→
Combined Features
→
High-Level Representation
→
Prediction
Depth allows complex features to be built from simpler ones.

3. التعلم الهرمي للميزات

تحول كل طبقة تمثيل الطبقة السابقة إلى تمثيل جديد.

تبني الطبقات المتقدمة ميزات معقدة انطلاقًا من ميزات أبسط.

4. Mathematical Form

For layer l:

z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
a⁽ˡ⁾ = φ(z⁽ˡ⁾)
  • W⁽ˡ⁾: weight matrix
  • b⁽ˡ⁾: bias vector
  • a⁽ˡ⁻¹⁾: previous-layer output
  • φ: activation function

4. الصيغة الرياضية

z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
a⁽ˡ⁾ = φ(z⁽ˡ⁾)

تستقبل كل طبقة خرج الطبقة السابقة وتطبق عليه تحويلًا خطيًا ثم دالة تنشيط.

5. ReLU Activation

ReLU(z)=max(0,z)
If z≤0

ReLU(z)=0

If z>0

ReLU(z)=z

Its derivative is:

ReLU'(z)=0 for z<0, and 1 for z>0

At z=0 the mathematical derivative is undefined; software implementations conventionally choose a subgradient, commonly 0.

ReLU is computationally simple and often reduces, but does not completely eliminate, vanishing-gradient difficulties.

5. دالة ReLU

ReLU(z)=max(0,z)

تعطي صفرًا للقيم السالبة، وتعيد القيمة نفسها عندما تكون موجبة.

ReLU'(z)=0 عندما z<0، و1 عندما z>0

عند z=0 لا تكون المشتقة الرياضية معرفة، وتختار التطبيقات البرمجية عادة قيمة شبه مشتقة تساوي صفرًا.

تمتاز ReLU بالبساطة الحسابية وتخفف غالبًا مشكلة تلاشي التدرج، لكنها لا تلغيها كليًا.

6. Vanishing Gradients

Backpropagation multiplies derivatives across many layers.

∂E/∂W⁽¹⁾ = ∂E/∂a⁽ᴸ⁾ · ∂a⁽ᴸ⁾/∂a⁽ᴸ⁻¹⁾ · ... · ∂a⁽¹⁾/∂W⁽¹⁾

If many derivative factors have magnitudes smaller than one, their product may become extremely small.

When gradients vanish, early layers learn very slowly.

6. تلاشي التدرج

يضرب الانتشار الخلفي مشتقات كثيرة عبر الطبقات.

إذا كانت مقادير عوامل المشتقات أصغر من الواحد، فقد يصبح حاصل ضربها صغيرًا جدًا.

عند تلاشي التدرج تتعلم الطبقات الأولى ببطء شديد.

7. Convolutional Neural Networks

CNNs are specialized for extracting local patterns from structured arrays such as images, time-frequency maps, and spatial measurements.

Feature Map = Input ∗ Kernel

The symbol ∗ denotes convolution or, in many software libraries, cross-correlation with a learned kernel.

Input
→
Convolution
→
Activation
→
Pooling
→
Prediction

7. الشبكات الالتفافية CNN

تستخدم CNN لاستخراج الأنماط المحلية من الصور أو الخرائط الزمنية-الترددية أو القياسات المكانية.

خريطة الميزات = الدخل ∗ النواة

يرمز ∗ إلى الالتفاف، أو إلى الارتباط المتقاطع في كثير من المكتبات البرمجية.

تتعلم المرشحات الالتفافية تلقائيًا الميزات المهمة من البيانات.

8. Recurrent Neural Networks

RNNs are designed for sequential data and maintain information from previous time steps.

hₜ = φ(Wₓxₜ + Wₕhₜ₋₁ + b)
yₜ = ψ(Wᵧhₜ + c)

The hidden state hₜ acts as a memory of earlier inputs, while ψ is selected according to the task, such as a linear function for regression or Softmax for classification.

8. الشبكات المتكررة RNN

صممت RNN للبيانات المتسلسلة، وتستخدم حالة مخفية للاحتفاظ بمعلومات من الأزمنة السابقة.

hₜ = φ(Wₓxₜ + Wₕhₜ₋₁ + b)
yₜ = ψ(Wᵧhₜ + c)

تمثل hₜ ذاكرة للمعلومات الحالية والسابقة، وتختار دالة الخرج ψ وفق نوع المسألة.

9. LSTM and Long-Term Dependencies

Long Short-Term Memory networks extend RNNs using gates and a cell state that control what information is stored, forgotten, and exposed.

Forget Gate

Controls discarded information.

Input Gate

Controls new stored information.

Output Gate

Controls the exposed hidden state.

9. شبكات LSTM

توسع LSTM بنية RNN باستخدام بوابات وحالة خلية تتحكمان في المعلومات التي يتم الاحتفاظ بها أو نسيانها أو إخراجها.

10. Training a Deep Network

Mini-Batch
→
Forward Pass
→
Loss
→

→
Optimizer
θₖ₊₁ = θₖ - η∇θJ(θₖ)

Common optimizers include SGD, Momentum, RMSProp, and Adam. Training data update the parameters, validation data guide model selection, and test data provide the final unbiased evaluation.

10. تدريب الشبكة العميقة

دفعة بيانات ← انتشار أمامي ← حساب الخطأ ← انتشار خلفي ← تحديث المعاملات
θₖ₊₁ = θₖ - η∇θJ(θₖ)

تستخدم بيانات التدريب لتحديث المعاملات، وبيانات التحقق لاختيار النموذج، وبيانات الاختبار للتقييم النهائي غير المتحيز.

11. Regularization

Dropout

Randomly disables units during training and is disabled during inference.

L2 Regularization

Adds a weight penalty to the loss.

Jᵣ = J + λ||W||²
Early Stopping

Stops training when validation performance no longer improves.

Data Augmentation

Creates valid transformed training examples.

11. الحد من فرط المطابقة

تشمل الطرائق Dropout وL2 والإيقاف المبكر وزيادة البيانات.

Jᵣ = J + λ||W||²

يستخدم Dropout أثناء التدريب فقط، بينما يعتمد الإيقاف المبكر على أداء بيانات التحقق.

12. Power-System Applications

Load Forecasting

Learn nonlinear temporal demand patterns.

Renewable Forecasting

Predict PV and wind generation.

Fault Diagnosis

Classify faults from measurements or signal maps.

State Estimation

Estimate system states from incomplete measurements.

Battery Management

Estimate SOC, SOH, and degradation.

Cybersecurity

Detect abnormal and malicious behavior.

12. تطبيقات نظم الطاقة

  • التنبؤ بالحمل والطاقة المتجددة.
  • تشخيص الأعطال.
  • تقدير حالة النظام.
  • تقدير SOC وSOH للبطاريات.
  • كشف الهجمات والسلوك غير الطبيعي.

13. Example: Sequence-Based Load Forecasting

An RNN or LSTM can receive a sequence of the previous 24 hourly loads:

[Pₜ₋₂₃, Pₜ₋₂₂, ..., Pₜ] → Network → P̂ₜ₊₁

Additional inputs may include temperature, hour, weekday, and holiday indicators. For time-series data, training, validation, and test sets should normally be split chronologically to avoid future-information leakage.

13. مثال: التنبؤ المتسلسل بالحمل

يمكن لـ RNN أو LSTM استقبال سلسلة من قيم الحمل للـ24 ساعة السابقة والتنبؤ بالحمل في الساعة القادمة.

[Pₜ₋₂₃, ..., Pₜ] → RNN / LSTM → P̂ₜ₊₁

يمكن إضافة درجة الحرارة والساعة واليوم ومؤشرات العطلات، ويجب عادة تقسيم بيانات السلاسل الزمنية زمنيًا لتجنب تسرب معلومات المستقبل.

14. Advantages and Limitations

Advantages
  • Automatic feature learning.
  • Strong nonlinear modeling.
  • Good performance with sufficient representative data.
Limitations
  • High data and computing requirements.
  • Complex tuning.
  • Limited interpretability.
  • Performance depends on data quality and distribution.

14. المزايا والقيود

المزايا
  • تعلم الميزات تلقائيًا.
  • تمثيل العلاقات غير الخطية.
  • أداء قوي عند توفر بيانات كافية وممثلة.
القيود
  • الحاجة إلى بيانات وحوسبة كبيرة.
  • صعوبة ضبط النموذج.
  • ضعف قابلية التفسير.
  • اعتماد الأداء على جودة البيانات وتوزيعها.

15. Summary

  • Deep networks contain multiple hidden layers.
  • Depth supports hierarchical feature learning.
  • ReLU is widely used in deep networks.
  • Vanishing gradients can slow early-layer learning.
  • CNNs learn local patterns in structured arrays.
  • RNNs and LSTMs model sequential data.
  • Regularization and proper validation help control overfitting.
  • Deep Learning supports forecasting, diagnosis, estimation, and monitoring in power systems.

15. الخلاصة
