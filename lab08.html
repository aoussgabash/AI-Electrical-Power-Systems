2. Power Balance

PB > 0 → Battery Discharge
PB < 0 → Battery Charge
Pgrid(k)=Pload(k)-PPV(k)-PB(k)

2. معادلة توازن القدرة

3. Grid Import and Export

Pgrid > 0 → Import
Pgrid < 0 → Export
Pimport=max(Pgrid,0)
Pexport=max(-Pgrid,0)

6. SOC Model

Charging: E(k+1)=E(k)+ηch|PB(k)|Δt
Discharging: E(k+1)=E(k)-PB(k)Δt/ηdis
SOC(k)=E(k)/Emax
SOCmin≤SOC(k)≤SOCmax

for gen = 1:maxGen
    J = zeros(popSize,1);

        E = zeros(1,T+1);
        E(1) = SOC0*Emax;
        socPenalty = 0;
        energyCost = 0;

        for k = 1:T
            if PB(k) < 0
                E(k+1)=E(k)+etaCh*abs(PB(k))*dt;
            else
                E(k+1)=E(k)-PB(k)*dt/etaDis;
            end

            SOC = E(k+1)/Emax;
            socPenalty = socPenalty ...

                + max(SOC-SOCmax,0)^2;
