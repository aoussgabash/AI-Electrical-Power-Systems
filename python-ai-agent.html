# Import datetime so the agent can read the current computer time.
# استيراد datetime كي يتمكن الوكيل من قراءة الوقت الحالي من الحاسوب.
from datetime import datetime

# Define the calculator tool.
# تعريف أداة الحاسبة.
def calculator(expression):
    try:
        # Evaluate the mathematical text in a restricted environment.
        # تقييم النص الرياضي ضمن بيئة محدودة.
        return eval(expression, {"__builtins__": {}})
    except Exception:
        return "Calculation failed | تعذر إجراء العملية الحسابية"

# Define the time tool.
# تعريف أداة الوقت.
def get_time():
    return datetime.now().strftime("%H:%M")

# Define the agent's decision-making function.
# تعريف دالة اتخاذ القرار داخل الوكيل.
def simple_agent(user_message):
    message = user_message.lower().strip()

    # Rule 1: choose the calculator.
    # القاعدة 1: اختيار الحاسبة.
    if message.startswith("احسب"):
        expression = message.replace("احسب", "").strip()
        result = calculator(expression)
        return f"نتيجة الحساب: {result}"

    # Rule 2: choose the time tool.
    # القاعدة 2: اختيار أداة الوقت.
    elif "الوقت" in message or "الساعة" in message:
        return f"الوقت الآن هو: {get_time()}"

    # Rule 3: answer a greeting directly.
    # القاعدة 3: الرد على التحية مباشرة.
    elif "مرحبا" in message or "السلام" in message:
        return "مرحبًا، أستطيع الحساب وإخبارك بالوقت."
    else:
        return "جرّب: احسب 5 * 6 أو ما الوقت؟"

# Keep the conversation running until the student writes "خروج".
# إبقاء المحادثة مستمرة حتى يكتب الطالب "خروج".
while True:
    user_input = input("الطالب: ")
    if user_input.lower() == "خروج":
        print("الوكيل: إلى اللقاء.")
        break
    answer = simple_agent(user_input)
    print("الوكيل:", answer)
Teaching and safety note | ملاحظة تعليمية وأمنية:
eval converts mathematical text into a Python expression. The empty __builtins__ dictionary removes the usual built-in functions from the evaluation environment, but a real public application should still use a dedicated safe mathematical parser.
تحوّل eval النص الرياضي إلى تعبير تنفذه بايثون، ويؤدي القاموس الفارغ __builtins__ إلى إزالة الدوال المدمجة المعتادة من بيئة التقييم. ومع ذلك، يجب في التطبيق العام الحقيقي استخدام محلل رياضي آمن ومخصص.

Why is it an agent? | لماذا هو وكيل؟

It receives a goal, makes a decision, selects an action, uses a tool, and returns a result.

لأنه يستقبل هدفًا، ويتخذ قرارًا، ويختار فعلًا، ويستخدم أداة، ثم يعيد النتيجة.

What did we build? | ماذا بنينا؟

A beginner rule-based agent whose decisions are explicitly written by the programmer.

بنينا وكيلًا تعليميًا قائمًا على قواعد يكتبها المبرمج بشكل صريح.

How Can This Agent Be Improved?

كيف يمكن تطوير هذا الوكيل؟
CURRENT VERSION | الإصدار الحالي

Fixed Rules | قواعد ثابتة

The programmer writes every decision using if, elif, and else. The agent recognizes only the words and cases that were defined in advance.

يكتب المبرمج كل قرار باستخدام if وelif وelse. ولا يفهم الوكيل إلا الكلمات والحالات المحددة مسبقًا.

FUTURE VERSION | الإصدار المستقبلي

Large Language Model (LLM) | نموذج لغوي كبير

A language model can understand requests written in many different forms, decide which tool is appropriate, use that tool, and generate a natural answer.

يمكن للنموذج اللغوي فهم الطلبات المكتوبة بصيغ مختلفة، وتحديد الأداة المناسبة، واستخدامها، ثم توليد إجابة طبيعية.

User Request | طلب المستخدم↓Language Model (LLM) | النموذج اللغوي↓Tool Selection | اختيار الأداة↓Natural Response | إجابة طبيعية
The current program teaches the structure of an agent. The future version replaces only the fixed decision rules with a language model; the tools and execution steps can remain.يشرح البرنامج الحالي البنية الأساسية للوكيل. في النسخة المستقبلية تُستبدل قواعد اتخاذ القرار الثابتة بنموذج لغوي، بينما يمكن أن تبقى الأدوات وخطوات التنفيذ نفسها.
